- Scope: Single public landing page for the PaperBridge native macOS app; Vue simulation only, not the native product.
- Mode and job: Persuade researchers by proving document fidelity, local processing, close-reading interactions, and export before asking them to build or inspect the source.
- First viewport: Editorial promise at left, live four-phase workbench at right, and an accurate “Build for macOS” terminal-guide action above the fold.
- Shipped story: Hero workflow → reconstruction pipeline → bilingual reader → capabilities → on-device privacy → FAQ → macOS build / Windows status.
- Live proof: Phase controls and playback; workflow tabs; language and reader-view controls; selected-term Translate/Explain plus annotation states; export and bookmark states; native FAQ disclosure.
- Visual world: Living bilingual critical edition in warm paper, cobalt, coral, deep ink, Newsreader, Manrope, solid annotation marks, and restrained structural shadow. No screenshots, gradients, glass, or generic SaaS card grid.
- Responsive boundary: Hero stacks below 1200px; navigation and major workspaces reflow below 960px; at 720px sidebars and secondary logs are removed while tabs, pages, phase controls, focus visibility, and core interactions remain.
- Product boundary: macOS 14+ source is available now through the terminal build guide; no signed direct download is claimed. Windows is labelled coming soon and disabled. MinerU is optional, PDFKit is the exact visual fallback, and Ollama runs locally.
- Evidence boundary: No testimonials, customer logos, usage metrics, independent benchmarks, paper uploads, remote-model claims, or claims that figures and formulas are translated.
- Finish status: Independent finish review passed after fixes. This brief and `DESIGN.md` document the shipped ground truth.
